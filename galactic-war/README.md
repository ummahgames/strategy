# Galactic War

A local browser strategy game. Open `index.html` in a WebGL-capable browser, or serve this folder with a static server. No installation or account is required.

Choose a preset or adjust production, deployment, movement, difficulty, objective, and map size before starting. Select a blue planet and then a destination; drag between planets to issue an order. In persistent-route mode orders toggle routes. In hybrid mode tapping sends a fleet and dragging toggles a route. Routes send ships above a ten-ship reserve. The side panel controls dispatch percentage, production upgrades, and route removal. Scroll to zoom; Space pauses. Capture enemy planets or complete the chosen objective.

This initial implementation includes a basic AI, generated maps, production upgrades, open movement and hyperlanes. It does not yet include save/resume, keyboard planet selection, advanced combat, specialized planets, resource economies, fog of war, multiplayer, a campaign, or the full visual effects and settings described in the planning discussion. Browser and physical-device playtesting remains necessary.
